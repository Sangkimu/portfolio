# SK Digital Solution — Digital Services Portfolio

**Tagline:** Technology. Creativity. Excellence.

A responsive portfolio website for SK Digital Solution, founded by Kevin Cheruiyot Sang. It presents virtual and administrative assistance, graphic design and branding, photography and multimedia, IT support, and professional document services.

## Built with
- HTML5
- CSS3
- JavaScript
- GitHub Pages (static hosting)

## Main pages
- `index.html` — business introduction, services, selected projects and contact details
- `gallery.html` — graphic design gallery
- `animation.html` — animation and video samples
- `cv.html` — founder's CV
- `pricing.html` — indicative service packages, scope notes and custom quotation links

## Publishing
The site can be published from the repository root using GitHub Pages. Keep existing asset paths intact when updating files.

## Before publishing
- Test the navigation and every project link.
- Confirm that all displayed contact details are current and intended for public use.
- Replace placeholder or incomplete project links with working destinations.
- Test the contact workflow on desktop and mobile. The project enquiry form collects service, budget, timeline and brief details, then opens a pre-filled Gmail compose window (or the default email app as a fallback). It is a client-side email handoff, not a server-backed form: the visitor must review and press Send. A true hosted submission inbox requires connecting a form provider or backend.
- Compress large video files where possible to improve loading on mobile connections.
